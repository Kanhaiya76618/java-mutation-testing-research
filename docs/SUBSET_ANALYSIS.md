# Equal-size test-subset analysis

Generated by `scripts/subset_analysis.py` from `data/v2/runs.csv` and `data/raw/` (1000 random subsets per size, seed 2026).

**How to read A12:** for subsets of the same size, A12 is the chance that a random subset that catches the bug scores higher than a random subset that does not. 0.5 means the score tells nothing beyond size; Vargha-Delaney thresholds are 0.56 small, 0.64 medium, 0.71 large.

## 4. Limits of this pilot

- 10 bug pairs from one project; per-pair A12 values describe how scores rank random subsets, not a population effect.
- The test pool is the changed test class(es) only, as in the PIT runs.
- Mutants detected only by timeout or memory error are left out (see section 1).
